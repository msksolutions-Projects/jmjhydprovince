# JMJ Hyderabad Province — four-part download

These four ZIP files together contain the **complete blue-and-white redesign project with the October 2026 PDF and Word-content updates**. They are divided for easier downloading.

1. Download **Part 1 – Project & Media** (includes application code and seven photo collections).
2. Download **Part 2 – PP Collections**.
3. Download **Part 3 – Assessment & Thanksgiving**.
4. Download **Part 4 – All PDF Documents** (includes the existing publication archive and the five new safeguarding PDFs).
5. On Windows, extract all four ZIPs **into the same destination folder**, for example `C:\JMJ-Redesign`. Each contains paths beginning with `frontend/`; Windows should merge those folders. Do not create an extra subfolder named after each ZIP.
6. Open the resulting `frontend` folder in VS Code. Run `npm ci`, then `npm run dev`.

All 12 image folders, 484 photographs, 12 gallery filters, pages, content, and documents are present once the four parts have been extracted together. Do not run the site from Part 1 alone, because some images and PDFs are in Parts 2–4.

## October 2026 document update

Part 4 includes the approved **94-page Safeguarding Policy** and **Annexures 1–4** as original PDFs in `frontend/public/documents/safeguarding/`. The site links to them from **What We Do → Safeguarding** and the **Media → Publications** page. A new **Who We Are → How We Live** page and supplementary Founder, History, Education and Social Work information are included from the supplied `Website Hyderabad.docx`.

Keep all PDF files from Part 4 inside the shared `frontend/public/documents/` folder.
