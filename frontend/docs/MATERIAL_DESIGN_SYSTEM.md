# Material Design System

## Principle

The interface uses Material UI as the single component system. The presentation follows the blue-and-white editorial concept: bold Manrope headings, DM Sans reading text, spacious layouts, navy/white split hero, refined image frames, and low-radius controls. Content and photo assets are unchanged.

## Layout

- Maximum content width: 1240px MUI `lg` container
- Main spacing rhythm: 8px Material grid
- Card and button radius: 3–6px
- Controls: minimum 44px target height
- Navigation: sticky app bar, desktop menus, mobile drawer
- Content pages: page header, content paper, optional sticky section index

## Accessibility

- Skip-to-content link
- Keyboard-accessible menus, dialogs, drawers and filters
- Visible focus treatment
- Semantic headings
- Responsive tables and mobile card alternatives
- Descriptive labels for search and navigation controls
